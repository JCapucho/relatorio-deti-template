## 19-04-2025 (v0.3)

- A opção `small-chapter` foi removida, ela nunca funcionou bem.
- A opção `language` foi adicionada a classe `capucho-report` permitindo
  alterar a linguagem do documento de português para outra suportada pelo
  `babel`.
- O comando `\relatorioAno` foi renomeado para `\relatorioData` para mostrar
  que é mais genêrico do que apenas um ano.
- A opção `final` foi adicionada para marcar um documento como completado, caso
  contrário o texto *Draft* será adicionado a primeira página do documento.
- A opção `noheader` foi adicionada a classe `relatorio-deti` permitindo
  remover o cabeçalho presente nas páginas normalmente.
- O cabeçalho foi alterado para alinhar o texto da cadeira a direita, mas
  mantendo o recorte do texto a direita.
